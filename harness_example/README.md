# 하네스 템플릿 (Harness Template)

> AI 에이전트(Claude Code 등)가 **코드를 다루기 전에 읽는 컨텍스트 레이어**의 출발 템플릿입니다.
> 코드는 없습니다. "이 프로젝트를 어떻게 안전하게·정확하게 다뤄야 하는가"를 알려주는 문서 골격만 있습니다.

---

## 이 템플릿을 쓰는 법

1. 이 `_harness_example/` 폴더를 새 프로젝트 루트로 **복사**합니다.
2. 아래 **플레이스홀더 규칙**에 따라 `{...}` 슬롯을 채웁니다.
3. **채우기 체크리스트**를 따라 도메인 값을 모두 교체합니다.
4. 다 채운 뒤 이 `README.md`(템플릿 안내)는 삭제하거나 프로젝트 README로 교체합니다.

---

## 플레이스홀더 규칙 (전 파일 공통)

| 표기 | 의미 | 처리 |
|------|------|------|
| `{슬롯명}` | 채워야 할 값 | 실제 값으로 **교체** |
| `{슬롯명 — 예: ...}` | 값 + 예시 힌트 | 예시 참고 후 교체, `— 예:` 부분 제거 |
| `<!-- 💡 ... -->` | 작성 가이드 주석 | 읽고 **삭제** (또는 유지) |
| `{service}` (폴더명) | 서비스/모듈 디렉토리 | 실제 서비스명으로 **폴더 rename** |
| `{feature}` (폴더명) | 기능 단위 디렉토리 | 실제 기능명으로 **폴더 rename** |

> 채우기 누락을 막으려면 작업 시작 전 `{` 문자를 전체 검색해 남은 슬롯이 없는지 확인하세요.

---

## Claude Code 로딩 메커니즘 (알아두면 안 헤맴)

- **루트 `CLAUDE.md`** 는 매 세션 항상 로드됩니다.
- **`{service}/CLAUDE.md`** 같은 하위 디렉토리 CLAUDE.md는 Claude Code가 **그 디렉토리 안의 파일을 다룰 때** 로드됩니다. 레포 루트에서만 작업하면 로드되지 않을 수 있습니다 → 도메인 규칙이 안 먹는 것 같으면 해당 서비스 폴더 기준으로 작업하세요.
- **`@상대경로` 구문**으로 CLAUDE.md가 다른 파일을 자동 import 합니다. 본 템플릿은 `{service}/CLAUDE.md` 에서 `@docs/INDEX.md` 를 import 해 인덱스를 매 세션 자동 로드합니다. 새 "항상 읽어야 할 문서"가 생기면 같은 방식으로 `@` 라인을 추가하세요.
- **빈 디렉토리**(`archive/reports/`, `archive/tasks/` 등)는 문서를 처음 이동할 때 생성하면 됩니다. git은 빈 폴더를 추적하지 않으므로, 미리 비워두려면 `.gitkeep` 파일을 넣으세요.

## 핵심 설계 원칙 (왜 이렇게 나뉘어 있나)

1. **CLAUDE.md 2계층** — 루트는 *안전·인프라 가드레일*(레포 전체), 서비스별 CLAUDE.md는 *코드·도메인 규칙*. 책임을 섞지 않습니다.
2. **INDEX 허브** — 새 세션은 `docs/INDEX.md`만 먼저 읽고 **필요한 문서만** 엽니다. 토큰 낭비 방지.
3. **문서 분류에 경계 규칙** — product(왜) / design(어떻게) / reports(분석 스냅샷) / tasks(실행 계획) / reference(매 세션) / guide(반복 양식) / archive(대체됨). "무엇이 어디로 가는가"를 못박습니다.
4. **SSOT(단일 진실 공급원)** — ⚠️ **변하면 안 되는 상수·공식(재시도 횟수, 백오프, 상태값 등)은 단 한 문서에만 표로 정의**하고, 다른 문서는 "→ 그 문서 참조"로 **인용만** 합니다. 같은 값을 두 곳에 적으면 반드시 어긋납니다.
5. **결정 추적성** — ADR(왜 결정했나) ↔ CLAUDE.md 금지사항(ADR 인용) ↔ history(언제 바뀌었나)를 삼각으로 연결합니다.

## 채우기 체크리스트

### 0. 복사 직후 — 폴더명부터 rename (먼저)
<!-- 💡 폴더명 {service}/{feature} 의 중괄호는 일부 셸·글롭에서 오인될 수 있습니다.
     실제 이름으로 가장 먼저 바꿔야 이후 경로 참조가 깨지지 않습니다. -->
- [ ] `{service}` → 실제 서비스/모듈명으로 폴더 rename
- [ ] `{service}/docs/product/{feature}` 및 `design/{feature}` → 실제 기능명으로 rename
- [ ] 예시용 파일명 슬롯(`{topic}_..._{YYYYMMDD}.md`, `{task}_plan.md`, `{superseded_doc}.md`) → 실제 파일로 교체하거나 삭제

### 1. 환경·안전 (`CLAUDE.md` 루트)
- [ ] `{OS}` / `{셸}` / `{컨테이너_런타임}` — **본인 개발 환경**으로 교체 (명령어 문법이 여기서 갈림)
- [ ] `{프로젝트명}` / `{프로젝트_목적}` / `{저장소_URL}` / `{개발_브랜치}` / `{메인_브랜치}`
- [ ] 절대 금지 사항 — 본 프로젝트에서 에이전트가 **절대 직접 하면 안 되는 명령**으로 교체
- [ ] 환경/배포 구조 표, 외부 서비스·환경변수 표

### 2. 코드·도메인 (`{service}/CLAUDE.md`)
- [ ] 폴더 `{service}` → 실제 서비스명으로 rename
- [ ] 언어/런타임/패키지 매니저/린터
- [ ] "추측 금지 상수표" — 에이전트가 지어내면 안 되는 도메인 상수 (상태값·키 형식 등)
- [ ] 코드 규약, 금지사항

### 3. 문서 (`{service}/docs/`)
- [ ] 폴더 `{feature}` → 실제 기능명으로 rename
- [ ] `INDEX.md` — 실제 보유 문서로 표 갱신
- [ ] `product/` PRD·기능정의서·ADR
- [ ] `design/` 아키텍처·신뢰성(또는 본 프로젝트의 핵심 품질 속성) 설계
- [ ] `reference/execution_guide.md` — 본인 환경 기준 실행 명령
- [ ] `reference/history.md` — 첫 줄부터 누적 시작
- [ ] `guide/report_style_guide.md` — 보고서 양식 (그대로 써도 무방)
- [ ] `guide/report-design-system.html` — 보고서 디자인 시스템 (도메인 중립, 그대로 재사용 가능)
- [ ] 예시로 남긴 `reports/`·`tasks/`·`archive/` 파일은 본인 것으로 교체하거나 삭제

## 폴더 구조

```
_harness_example/
├── README.md                         <- (이 파일, 다 채운 뒤 삭제)
├── CLAUDE.md                         <- 루트: 안전·인프라 가드레일
└── {service}/
    ├── CLAUDE.md                     <- 서비스: 코드·도메인 규칙
    └── docs/
        ├── INDEX.md                  <- 문서 허브 (먼저 읽기)
        ├── product/{feature}/
        │   ├── prd.md                <- 왜 만드는가
        │   ├── feature-spec.md       <- 무엇을/어떻게 동작
        │   └── adr.md                <- 왜 그렇게 결정했나
        ├── design/{feature}/
        │   ├── architecture.md       <- 어떻게 구현
        │   └── reliability_design.md <- 핵심 품질 속성 상세 (SSOT 상수 위치)
        ├── reports/                  <- 분석 스냅샷 (날짜 박힌 보고서)
        ├── tasks/                    <- 순수 실행 계획만
        ├── reference/
        │   ├── execution_guide.md    <- 매 세션: 실행 방법
        │   └── history.md            <- 매 세션: 변경 이력
        ├── guide/
        │   ├── report_style_guide.md <- 보고서 작성 양식
        │   └── report-design-system.html
        └── archive/                  <- 대체된 문서 (삭제 금지, 안 읽어도 됨)
```
