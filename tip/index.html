클로드

Claude
기본

Anthropic이 만든 AI 어시스턴트.

질문에 답하고, 파일을 처리하고, 코드를 작성하는 만능 보조자입니다.

세 모델로 구성됩니다. Opus 4.7 (가장 강력한 지능), Sonnet 4.6 (속도·지능 균형), Haiku 4.5 (가장 빠른 응답). Constitutional AI 방식으로 학습해 답변 원칙이 투명합니다.

프롬프트

Prompt
기본

AI에게 보내는 질문이나 지시.

AI에게 보내는 편지입니다. 구체적일수록 원하는 답을 받습니다.

좋은 프롬프트의 4요소: 역할 ("번역가로서"), 맥락 ("이 파일을 바탕으로"), 형식 ("표 형태로"), 제약 ("3문장 이내로"). 모두 포함할 필요는 없지만, 많을수록 정확한 결과를 얻습니다.

🔢

토큰

Token
기본

AI가 텍스트를 처리하는 최소 단위.

단어를 1~3개 조각으로 쪼갠 것입니다. "안녕하세요"는 약 3~4토큰입니다.

Claude Sonnet 4.6 기준 컨텍스트 윈도우는 200K 토큰 (약 15만 단어). 입력+출력 토큰 합계가 이 한계를 넘으면 오류가 발생합니다. API 요금도 토큰 단위로 청구됩니다.

컨텍스트 윈도우

Context Window
기본

AI가 한 번에 읽고 기억할 수 있는 텍스트 양.

책상 위에 펼쳐놓을 수 있는 공간입니다. 공간이 넘치면 오래된 내용부터 사라집니다.

Claude Sonnet 4.6의 컨텍스트 윈도우는 200K 토큰 (약 150페이지 분량). 대화가 길어질수록 초반 내용을 잊을 수 있습니다. 프로젝트 파일과 지침도 이 공간을 사용하므로 파일 크기를 감안해야 합니다.

Constitutional AI

Constitutional AI
기본

원칙 문서를 기반으로 AI가 스스로 답변을 평가하고 개선하는 학습 방식.

일반 AI는 사람이 "좋아요/싫어요"로 학습시킵니다. Constitutional AI는 AI가 헌법(원칙)을 보고 스스로 채점합니다.

Anthropic이 개발한 학습 방법론. 학습 원칙이 공개 문서로 존재해 "왜 이렇게 답하는지" 추적할 수 있습니다. 답변의 투명성과 안전성을 높이는 것이 핵심 목표입니다.

프로젝트

Project
제품 기능

대화·파일·지침을 하나로 묶는 작업 공간.

업무별로 분리된 폴더입니다. 마케팅 프로젝트와 개발 프로젝트가 서로 섞이지 않습니다.

프로젝트에 파일을 올리면 모든 대화에서 자동 참조됩니다. 지침(시스템 프롬프트)을 설정하면 "항상 한국어로, 요점만"처럼 매 대화에 자동 적용됩니다. Pro 이상에서 팀 공유 가능. 파일 1개당 최대 30MB, 컨텍스트 200K 토큰 한도.

메모리

Memory
제품 기능

대화 내용을 자동 요약해 다음 세션에도 기억하는 기능.

AI가 자동으로 노트를 남겨두는 것입니다. "저는 마케터입니다"라고 말하면 다음 대화에서도 기억합니다.

Web Search

커스텀 스타일

Custom Style
제품 기능

응답 길이·어조·형식을 전역으로 고정하는 설정.

MCP

Model Context Protocol
연결

AI가 외부 도구와 통신하는 개방형 표준 규격.

USB처럼 꽂으면 연결됩니다. 표준 규격이라 MCP를 지원하는 어떤 도구든 Claude와 연결할 수 있습니다.

Anthropic이 주도하는 오픈소스 표준. Claude Desktop에서 claude_desktop_config.json에 서버 정보를 입력해 연결합니다. GitHub, Slack, DB 등 수백 개 커뮤니티 서버가 공개되어 있습니다.

Connector

Desktop Extension (.mcpb)
연결

CLAUDE.md

CLAUDE.md
자동화

프로젝트 규칙을 적어두는 파일 — Claude Code가 매 세션 자동으로 읽습니다.

Claude에게 "이 프로젝트에서 지켜야 할 규칙"을 미리 전달하는 메모입니다.

프로젝트 루트에 CLAUDE.md를 만들면 Claude Code가 세션 시작 시 자동 로드합니다. 주요 활용: 규칙 ("원본 삭제 전 백업"), 금지 경로, 파일 명명 규칙, 응답 방식 지정. 비개발자도 텍스트 에디터로 작성할 수 있습니다.

서브에이전트

Sub-agent
자동화

메인 Claude가 작업 일부를 별도 Claude 인스턴스에 위임하는 기능.

팀장이 팀원에게 업무를 배분하는 것입니다. 여러 작업을 동시에 진행할 수 있습니다.

Claude Code에서 Task tool로 서브에이전트를 생성합니다. 컨텍스트가 격리되어 대규모 작업 (전체 코드베이스 감사, 여러 파일 동시 수정)을 병렬 처리합니다. 각 서브에이전트는 독립적인 컨텍스트 윈도우를 가집니다.

hooks

Hooks
자동화

특정 이벤트에 자동으로 실행되는 명령.

특정 행동이 일어날 때 자동으로 켜지는 트리거입니다.

.claude/settings.json의 hooks 배열에 정의합니다. 이벤트 종류: PreToolUse (도구 실행 전), PostToolUse (실행 후), Stop (세션 종료). 활용 예: 커밋 전 자동 린트, 세션 종료 시 변경 내역 요약 저장.

하네스

Harness
자동화

Claude를 감싸는 세팅 스캐폴딩 — CLAUDE.md, hooks, 권한 설정의 총합.

같은 트럭도 잘 정비된 트럭이 더 멀리, 더 안전하게 달립니다. 하네스는 Claude가 일관되고 안전하게 작동하도록 만드는 장치입니다.

"하네스 엔지니어링"은 단발 프롬프트를 반복 가능한 워크플로우로 만드는 작업입니다. 구성 요소: CLAUDE.md (규칙 주입) + hooks (이벤트 자동화) + settings.json (권한 제어) + 슬래시 커맨드 (작업 표준화). 같은 모델도 하네스 설계에 따라 생산성이 크게 달라집니다.

슬래시 커맨드

Slash Command
자동화

/명령어 형태로 자주 쓰는 작업을 단축 실행하는 기능.

자주 쓰는 긴 문장을 단축키 하나에 저장해두는 것입니다.

.claude/commands/ 폴더에 마크다운 파일을 만들면 자동으로 등록됩니다. 예: weekly-report.md → /weekly-report로 보고서 자동 생성. 비개발자도 반복 작업을 자동화할 수 있습니다.

권한 모드

Permission Mode
자동화

Claude Code가 어떤 도구를 자동 허용할지 제어하는 설정.

집에 들어온 사람이 어느 방까지 들어올 수 있는지 정해두는 것입니다.

.claude/settings.json의 allowedTools (자동 허용)와 dangerouslyAllowedTools (위험 도구 자동 허용)로 설정합니다. 매번 승인 없이 Read만 허용하거나, 신뢰하는 작업에 Edit·Write·Bash까지 자동 허용할 수 있습니다.
