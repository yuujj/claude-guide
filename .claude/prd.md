# 클로드 가이드 — 사용자 정의서 (PRD)

> 최초 작성: 2026-04-30
> 근거 문서: ADR-001 (청중 전략), ADR-002 (허브 구조)

---

## 사이트 목적

한국어 사용자가 Claude (Web / Desktop / Code)를 처음 접한 후 실제로 활용하기까지의
진입 장벽을 낮춘다. "가입은 했는데 뭘 할 수 있는지 모르겠다"는 상태에서
"내 업무에 어떻게 쓰는지 알았다"는 상태로 이동시키는 것이 핵심 목표다.

---

## 페르소나

### P1 — 비개발자 탐색자

| 항목 | 내용 |
|------|------|
| **대표 직군** | 직장인, 학생, 프리랜서 |
| **기술 배경** | 코딩 경험 없음. 스마트폰과 오피스 툴은 익숙함 |
| **Claude 경험** | 가입만 해봤거나 완전 처음 |
| **핵심 목표** | 글쓰기·분석·파일 정리 같은 실제 업무에 Claude를 활용하고 싶다 |
| **핵심 페인포인트** | 기술 용어(MCP, CLI, hooks)에 겁먹음. "이게 나한테 맞는 건지" 불명확. 설치·설정 화면이 나오면 이탈 |
| **성공 기준** | 10분 안에 자신의 업무 시나리오를 찾고, 실제로 Claude를 시작한다 |
| **설계 함의** | 용어 툴팁 필수. `[고급]` 배지로 "건너뛰어도 됨" 신호. CLI보다 웹/데스크탑 GUI 먼저 안내 |

---

### P2 — 개발자 / 파워유저

| 항목 | 내용 |
|------|------|
| **대표 직군** | 개발자, 데이터 분석가, 자동화 관심자 |
| **기술 배경** | 터미널·JSON 편집 가능. 타 AI 도구(Cursor, Copilot 등) 경험 있을 수 있음 |
| **Claude 경험** | 이미 사용 중이거나, 더 체계적으로 쓰고 싶어서 방문 |
| **핵심 목표** | 하네스 세팅(CLAUDE.md, hooks, MCP), 효율적인 반복 워크플로우 구축 |
| **핵심 페인포인트** | 입문 설명이 너무 많음. 스펙과 실전 예시를 바로 찾고 싶음. 설명 없이 코드 블록으로 보여주면 충분 |
| **성공 기준** | 2클릭 이내에 원하는 설정 정보에 도달하고, 복붙 가능한 실전 예시를 얻는다 |
| **설계 함의** | 사이드바 ToC + `[고급]` 배지로 직접 점프. disclosure로 기술 상세 묶기. settings.json 전체 레퍼런스 제공 |

---

### P3 — 중간 사용자

| 항목 | 내용 |
|------|------|
| **대표 직군** | 디자이너, PM, 마케터, 호기심 많은 일반 사용자 |
| **기술 배경** | CSS·스프레드시트는 다룰 수 있음. 터미널은 낯섦 |
| **Claude 경험** | 기본 채팅은 써봤고, 더 잘 쓰고 싶어서 방문 |
| **핵심 목표** | 프로젝트·아티팩트·MCP 같은 기능이 "나한테도 유용한지" 탐색 |
| **핵심 페인포인트** | "이건 개발자용인가?" 판단 불명확. 이진 선택(비개발자/개발자)으로 잘못된 경로로 유도됨 |
| **성공 기준** | 이진 선택 없이 자신의 수준에 맞게 자연스럽게 콘텐츠 깊이를 조절할 수 있다 |
| **설계 함의** | 이진 선택 카드 없음. disclosure + 배지로 자율 탐색. Claude Code도 비개발자 예시 먼저 배치 |

## 범위 외 사용자

| 사용자 유형 | 이유 |
|------------|------|
| Anthropic API 직접 사용자 | 개발자 문서(docs.anthropic.com) 별도 존재 |
| 영문 콘텐츠 이용자 | 이 사이트는 한국어 전용 |
| Claude for Enterprise 관리자 | 엔터프라이즈 설정·SSO·감사 로그 등은 미포함 |

## 설계 제약

| 제약 | 출처 |
|------|------|
| 비개발자/개발자 이진 선택 강요 없음 — 적응형 컴포넌트로 대응 | ADR-001 |
| 허브는 제품 기준, 페이지 내부는 작업 기준 | ADR-002 |
| 순수 정적 HTML/CSS/JS (빌드 도구 없음) | CLAUDE.md |
| GitHub Pages 배포 (branch: main, root /) | CLAUDE.md |
| Claude Code를 "개발자 전용"으로 닫지 않음 | content-plan.md |
