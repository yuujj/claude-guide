세팅

나만의 클로드 세팅하기

한 번 세팅해두면, 매번 같은 맥락을 다시 설명하지 않아도 됩니다. 세팅은 적용 범위에 따라 3가지 레이어로 구성됩니다.

세팅위치적용 범위플랜
프로필 지침 설정 → 개인 환경설정 모든 대화 전역 전체
커스텀 스타일 채팅 하단 → 스타일 사용 모든 대화 (전환 가능) 전체
프로젝트 지침 프로젝트 → 지침 설정 해당 프로젝트만 전체
메모리 설정 → Capabilities → Memory 프로젝트 외 모든 독립 대화 전체

왼쪽 하단 이니셜 → 설정 → 개인 환경설정에 작성합니다. 프로젝트 유무와 무관하게 모든 대화의 첫머리에 자동 적용됩니다. 업무 맥락, 선호 언어, 응답 방식을 적어두면 됩니다.

지침 예시
- 항상 한국어로 답변
- 설명은 간결하게, 핵심 먼저
- 수치나 표를 활용해 구체적으로
- 질문이 모호하면 먼저 확인 요청

채팅 입력창 하단 "스타일 사용"에서 선택합니다. 4가지 기본 프리셋과 커스텀 스타일을 제공합니다. 대화 도중에도 언제든 전환할 수 있습니다.

Normal 기본 — 균형 잡힌 응답
Concise 짧고 직접적 — 핵심만
Formal 격식체 — 공식 문서·비즈니스
Explanatory 교육적·설명적 — 개념 학습
커스텀 내 글 샘플 업로드 또는 선호도 직접 기술

프로젝트 화면에서 "지침 설정"을 클릭합니다. 프로필 지침보다 구체적인 업무별 규칙을 적어두세요. 해당 프로젝트의 모든 대화에만 적용됩니다.

지침 예시 — 마케팅 프로젝트
# 프로젝트 컨텍스트
스타트업 B2B SaaS 마케팅 팀 작업입니다.

# 응답 방식
- 항상 한국어로 답변
- 핵심 먼저, 설명은 3문장 이내
- 수치·표 적극 활용

# 주의사항
- 경쟁사 직접 비교 시 중립적 표현 사용

대화 내용을 자동으로 요약해 다음 세션에 반영합니다. 24시간 이내에 업데이트됩니다.

확인·편집·삭제: 설정 → Capabilities → View and edit memory

프로젝트마다 독립적인 메모리 공간을 사용합니다 — 업무 프로젝트 메모리가 개인 대화에 섞이지 않습니다. 시크릿 채팅은 메모리에 저장되지 않습니다.

활용

이런 걸 할 수 있어요

질문, 글쓰기, 파일 분석, 인터랙티브 앱 제작까지 — 채팅 하나로 가능합니다.

💬

질문·학습

어려운 개념을 내 수준에 맞춰 설명받고, 후속 질문으로 깊이 들어갑니다.

"양자역학을 중학생 수준으로 설명하고, 이해도 확인할 퀴즈 3개 만들어줘"
✍️

글쓰기·번역

상황과 톤을 주면 초안을 만들어줍니다. 커스텀 스타일로 회사 톤을 고정할 수도 있습니다.

"거래처에 납기 지연 안내 메일 — 정중하지만 단호하게, 3문단으로"
🖼️

이미지·파일 분석

PDF, 엑셀 스크린샷, 영수증 사진을 업로드하면 내용을 읽고 정리합니다.

"이 영수증 10장을 표로 정리하고 월별 지출 카테고리 분석해줘"
⚡

만들기 (아티팩트)

채팅 옆에 실시간으로 프로토타입이 렌더링됩니다. 코드를 몰라도 됩니다.

"연봉 협상 시뮬레이터 — 연봉/세금/실수령액 보여주는 인터랙티브 페이지"
기능

핵심 기능

대화·파일·지침을 하나의 작업 공간으로 묶습니다. 지침은 해당 프로젝트의 모든 대화에 자동 적용되고, 파일은 매번 업로드하지 않아도 항상 참조됩니다.

파일 업로드 지원 형식

PDF · DOCX · CSV · TXT · HTML · XLSX · JSON · 이미지(JPEG·PNG·GIF·WebP) — 파일당 최대 30MB, 프로젝트 전체 약 200K 컨텍스트

무료: 최대 5개 프로젝트 Pro 이상: RAG 자동 활성화 Team/Enterprise: 팀 공유

Pro 이상에서는 파일이 컨텍스트 한도에 가까워지면 RAG(검색 증강 생성)가 자동 활성화되어 관련 내용만 로드합니다. Team/Enterprise에서는 프로젝트를 팀원과 공유하고 "보기·채팅" / "편집" 권한을 따로 설정할 수 있습니다.

채팅 오른쪽 전용 패널에 결과물을 실시간으로 렌더링합니다. 수정 요청을 하면 패널 안에서 바로 반영됩니다.

지원 타입

HTML 웹페이지 React 컴포넌트 SVG 코드·마크다운 Excel · PPT · PDF 차트·다이어그램

버전 기록 — 이전 버전으로 되돌아갈 수 있습니다.

게시·공유 — Publish 버튼으로 공개 링크를 생성하거나 다른 웹사이트에 임베드 코드로 삽입할 수 있습니다.

리믹스 — 다른 사람이 게시한 아티팩트를 복사해 내 것으로 수정할 수 있습니다.

대화가 끝난 뒤 Claude가 핵심 내용을 자동으로 요약해 다음 세션에 반영합니다. 24시간 이내에 업데이트됩니다.

주로 기억하는 내용

업무 방식·선호 도구·커뮤니케이션 스타일·내가 수정 요청한 사항 등. 민감한 개인 정보는 저장하지 않습니다.

관리 방법

설정 → Capabilities → "View and edit memory"에서 Claude가 기억하는 내용 전체를 확인·수정·삭제할 수 있습니다.

프로젝트별 독립 메모리 시크릿 채팅 미저장 타 AI에서 메모리 가져오기

실시간 웹을 검색하여 최신 정보를 참조합니다. Claude의 학습 데이터에 없는 오늘 뉴스, 최신 시세, 최근 업데이트된 공식 문서도 답변에 포함할 수 있습니다. 채팅 하단 도구 메뉴에서 활성화합니다.

응답 방식을 세 레이어로 고정합니다. 설정이 겹칠 경우 프로젝트 지침 → 프로필 지침 → 스타일 순으로 적용됩니다.

프로필 지침 — 설정 → 개인 환경설정

모든 대화에 적용되는 전역 규칙. "항상 한국어로, 핵심만" 같은 개인 선호도.

커스텀 스타일 — 채팅 하단 → 스타일 사용

Normal · Concise · Formal · Explanatory 4가지 프리셋 또는 커스텀. 대화 중 전환 가능.

프로젝트 지침 — 프로젝트 → 지침 설정

해당 프로젝트에만 적용되는 업무별 규칙. 역할·형식·금지 사항 등 구체적으로 작성.
